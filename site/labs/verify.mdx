## Running it

```bash
cd labs/p1/week-01
make verify          # full suite
make verify TRACK=basic
make bench           # where the lab has a performance target
```

Exit code 0 means the track passes. Anything else prints the failing assertion and the lesson
section that covers it.

## The rubric

Every lab is scored 0–3 on four dimensions. Grade yourself before you look at any solution.

| Dimension | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| **Correctness** | fails tests | happy path only | edge cases handled | adversarial inputs handled |
| **Code quality** | it works | readable | tested and typed | a reviewer would approve unchanged |
| **Performance** | untested | measured | meets the stated budget | beats it, with evidence |
| **Explanation** | none | a README | reasoning documented | trade-offs defended in writing |

A 3 on **Explanation** is what most people skip and what most interviews actually test.
