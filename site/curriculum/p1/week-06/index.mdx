## Outcome

<Note>
By Sunday you have designed, built, secured, tested, load-tested and deployed an async API with
validated contracts and real auth — and you can say what its capacity is and which resource limits
it.
</Note>

Week 5 made you the client. This week you are the server, and every decision you made looking at
someone else's API comes back as your own: which status code, which error shape, how to page, how
to make a retry safe, how not to leak another tenant's data.

This is the most load-bearing week in Phase 1 for what comes after. The service you build here is
upgraded with an LLM in Week 26 and instrumented with distributed tracing in Week 32. Keep the
repo.

<Note>
**Measured.** Every number in this week was produced on this machine against exactly those
versions — Apple Silicon (11 cores, 18 GB, macOS), uvicorn 0.34 single worker, `ab -k` for load.
Nothing here is modelled from published benchmarks. The reproduction log, with commands and raw
output, is committed at `evidence/phase-1-w05-08-measurements.md`; see [About the numbers](/start/about-the-numbers) for what that label means.

Absolute throughput tracks your core count and load average. The ratios — the 27.8× collapse from
blocking inside `async def`, argon2id against bcrypt at each cost, `model_validate` against
`json.loads` plus validate — are the claims worth carrying.
</Note>

## What you should be able to say out loud by Sunday

1. "That is a `409`, not a `422` — the request is valid, the state conflicts."
2. "It is `async def` with a blocking call, which is why latency is seconds and CPU is idle."
3. "The normaliser has to be `mode='before'`, or the constraint rejects the value first."
4. "The route check passed and the object check is missing — that is IDOR."
5. "The knee is at 100 concurrent; Little's Law says 143 requests are queued for a 40-slot pool."

## Prerequisites check

You should be able to explain what `await` does (`P1-W04-M4`), read an HTTP request and response
(`P1-W05-M1`), and write a pytest test with a fixture (`P1-W03-M5`). If any of those is shaky, the
`async def` section of module 2 will not land — go back for an hour first; it is cheaper than
debugging a frozen event loop later.

## What this week feeds

Week 7 designs the schema your API stores data in. Week 8 makes that storage correct under
concurrency and fast under load, and rewires this exact service to use it. The idempotency keys you
design in module 1 become real database rows in `P1-W08-M1`; the object-level checks from module 4
become a repository boundary in `P1-W08-M5`.
