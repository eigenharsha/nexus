## Outcome

<Note>By Sunday you write Python that a reviewer would approve unchanged: typed, tested, with classes that enforce their own invariants and data structures chosen from measured costs rather than habit.</Note>

Five things you cannot do today and will be able to do by Sunday night:

1. Choose between dict, class, `__slots__`, dataclass, NamedTuple and columnar arrays for a million records, from measured numbers: **268, 171, 139, 171, 152 and 28 bytes each**.
2. Process a 2 GB file in **14 MB of memory** — and explain why the streaming version is also **3.3× faster**.
3. Implement `@property` from scratch as a descriptor and pass the builtin's tests.
4. Find a bug with `hypothesis` that four example tests and 100% branch coverage missed.
5. Set up a project so a fresh machine is productive in under 5 seconds: `uv venv` 0.033 s, install 0.135 s, `ruff check` 0.059 s on 30,000 lines.

## Why this week

Weeks 1 and 2 were about the machine and the environment. This week is about the language you will spend the next 28 weeks in.

The framing that makes Python make sense: **everything is an object, a name is a label bound to one, and nothing is ever copied unless you ask.** Almost every Python surprise — aliasing, mutable defaults, `is` versus `==`, why a cache returns mutated data — is a consequence of that one sentence. Get it right now and the rest of the course inherits it.

The second half of the week is about writing code other people can change. Types, tests, tooling and class design are not ceremony; they are what makes a codebase survive contact with a second author.

## Set up before Monday

```bash
# uv replaces pip, venv, pyenv and pip-tools. One binary.
curl -LsSf https://astral.sh/uv/install.sh | sh     # or: brew install uv

uv python install 3.13
uv venv --python 3.13
source .venv/bin/activate
uv pip install ruff mypy pytest pytest-cov hypothesis

python3 --version    # 3.13.2
ruff --version       # 0.16.5 (0.5+ is fine)
mypy --version       # 2.3.1 (1.10+ is fine)
pytest --version     # 9.1.1 (8+ is fine)
```

Generate the 2 GB JSONL fixture Module 2 and the lab use:

```bash
python3 labs/p1/week-03/fixtures/genlog.py 2000000000 > events.jsonl   # ~12.2M records
ls -lh events.jsonl
```

<Warning>
**`resource.getrusage().ru_maxrss` is in BYTES on macOS and KILOBYTES on Linux.** Every memory
measurement this week depends on getting that right; the difference is a factor of 1,024 and
the wrong number still looks plausible. Branch on `sys.platform`, and cross-check with
`tracemalloc`, which is portable and measures what Python allocated rather than what the OS
kept resident.
</Warning>

## What "done" looks like

- A `ledger` package on TestPyPI, installable with `uv pip install -i https://test.pypi.org/simple/ ledger`.
- `mypy --strict` clean, `ruff` clean, 90%+ **branch** coverage that you can defend as meaningful.
- A second storage backend added without editing a line of core code — with the diff as proof.
- Hypothesis invariant tests showing the balance never drifts under any sequence of operations, and at least one bug they found.
- Your own measured memory table for a million records, with `tracemalloc` and RSS both reported.
- One diagram redrawn from memory and committed.
