Nexus uses [Mintlify hidden pages](https://www.mintlify.com/docs/organize/hidden-pages) for
drip release. Unreleased weeks are fully written and deployed, but hidden from navigation and
from search until the cohort reaches them.

## How it works

Every week is a group in `docs.json`. Unreleased groups carry `"hidden": true`:

```json
{
  "group": "Week 9 — Digital Logic → CPU (Nand2Tetris I)",
  "hidden": true,
  "pages": ["curriculum/p2/week-09/index", "..."]
}
```

Hidden groups are absent from the sidebar and excluded from search, sitemaps and AI context,
but remain reachable by direct URL.

## Releasing a week

The release point lives in one place — `site/generate.py`:

```python
RELEASED_THROUGH_WEEK = 8   # bump this, regenerate, deploy
```

```bash
python3 site/generate.py && git commit -am "release week 9" && git push
```

<Warning>
**Hidden is not private.** A learner who guesses `/curriculum/p2/week-09/index` will read it.
That's acceptable for pacing; it is *not* acceptable for anything confidential. Never put exam
material, learner data or credentials on a hidden page.
</Warning>

## What is permanently hidden

| Area | Why |
| --- | --- |
| **Solutions tab** | Linked from each module and lab, deliberately not browsable. Reading them before attempting is the main way to waste this course. |
| **Instructor tab** | Session plans, rubric internals, defence scripts, and the notes on where cohorts predictably stall. |
| **Future weeks** | Pacing. A cohort that reads ahead to Week 27 before Week 11's linear algebra will not understand Week 27. |

## Indexing

`docs.json` sets `"seo": { "indexing": "navigable" }` — only pages reachable through the
navigation are indexed by search engines. To publish everything (including hidden pages), that
would become `"indexing": "all"`. Don't change it without a reason.

## Cohort checklist

<Steps>
  <Step title="Friday before the new week">Bump `RELEASED_THROUGH_WEEK`, regenerate, deploy.</Step>
  <Step title="Verify the sidebar">The new week appears; the following week does not.</Step>
  <Step title="Check the lab">`make verify` is green on the solution and red on the starter, on a clean machine.</Step>
  <Step title="Announce with the diagram">Post the week's hero sketch, not a wall of text.</Step>
</Steps>
