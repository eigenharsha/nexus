## Reference solution — `P4-W31-M2`

### The kappa progression is the deliverable

Not the final number — the sequence, because it shows what actually worked.

| Change | κ |
| --- | --- |
| "Rate 1–5", no rubric, no reasoning | 0.11 |
| + three-criterion rubric | 0.29 |
| + reasoning required before each answer | 0.44 |
| + **binary criteria replacing the 1–5 scale** | 0.61 |
| + "length is NOT quality" and a negative anchor per criterion | 0.67 |
| + two worked examples per criterion | 0.71 |
| (human–human ceiling on the same 50) | 0.78 |

**Binary criteria are the biggest single jump** and the least intuitive change. A 1–5 scale asks the
judge to place four boundaries you never defined; three yes/no questions ask three decisions you did
define. Sum them for a 0–3 score if you want a number.

### The calculation to run in front of anyone quoting agreement

```python
p_o = 0.62                                   # 31 of 50 matched
p_e = 0.74 * 0.60 + 0.26 * 0.40              # judge said good 74%, human 60%
kappa = (p_o - p_e) / (1 - p_e)              # 0.16
```

Sixty-two per cent agreement is κ 0.16 — very nearly a machine that says "good" most of the time.
Every one of the 13 false positives came with fluent reasoning. **The reasoning is not evidence.**

### Reference numbers

| | Value |
| --- | --- |
| Position bias, single order, equal-quality pairs | 61.5% pick the first |
| After swap-and-tie | 50.0% by construction, κ 0.83 against a consistent oracle |
| Verbosity bias, 1–5 no rubric / binary criteria | +0.6 / +0.05 on identical content |
| Self-preference for own model family | 57% vs a 50% human control |
| Haiku vs Opus as judge: holistic / groundedness | κ 0.58 vs 0.71 / 0.69 vs 0.74 |
| Split rubric cost | $0.71 per 100 cases vs $1.80, κ 0.70 |

## Why this solution and not the obvious one

**Obvious:** tell the judge in the prompt not to be biased by position. Measured effect: κ 0.83 to
0.84 — nothing. Running both orders and treating disagreement as a tie fixes it completely.
**Mechanism beats instruction**, here and in Module 4 and in Week 29 M4.

**Obvious:** chase a higher kappa. Your annotators agreed at 0.78. A judge at 0.71 is close to as
good as a person, and pushing higher is fitting to label noise. Report the human ceiling or your
number is uninterpretable.

**Obvious:** use the strong model for every criterion. On mechanical criteria the cheap model was
within 0.05 kappa at a fifth of the price. Split the rubric; it was a 61% cost reduction for 0.01 of
agreement.

## The two wrong turns worth knowing about

1. **Reading the judge's score before writing our own labels.** Anchoring is large, and the resulting "human labels" were agreement with the judge. Label blind, always, and if you have already looked, discard those cases.
2. **Reporting only the aggregate kappa.** At 0.44 the per-criterion matrix showed groundedness was nearly perfect and actionability was worthless. Fixing one criterion's definition was a day's work; polishing the rubric generally would never have found it.

## Grading notes

**3/3 on Measurement rigour:** kappa, per-criterion confusion, human–human ceiling from at least 20
double-labelled cases, both biases measured before and after mitigation, and the threshold recorded
in the repository *before* the first measurement.

**Anything that gates CI on a judge below the stated threshold is an automatic fail**, however good
the rest is. That is the specific self-deception this module exists to prevent.

**Common losses:** raw agreement reported as if it were kappa; no human ceiling; pairwise comparison
without order swapping; and a judge tuned against the same 50 cases it is then validated on, which
is the eval equivalent of testing on the training set.
