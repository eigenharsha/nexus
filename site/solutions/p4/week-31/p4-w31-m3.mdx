## Reference solution — `P4-W31-M3`

### Read the four numbers as a diagnosis, not a score

| Metric | Ours | What it tells you |
| --- | --- | --- |
| End-to-end | 0.78 | Nothing about where the problem is |
| Context recall@5 | 0.91 | Retrieval finds it. Not the bottleneck. |
| Context precision@5 | 0.62 | Two of five chunks are noise. **Here.** |
| Faithfulness | 0.88 | Some hallucination, likely from the distractor chunks |
| Answer relevancy | 0.84 | Some drift off the question |

The fix followed in ten seconds: cut `k` from 5 to 3 after re-ranking. Precision 0.62 → 0.81,
faithfulness 0.88 → 0.93 (fewer distractors to hallucinate from), end-to-end 0.78 → 0.86, **prompt
untouched**. Every team we have shown this to assumed the prompt was the problem.

### The attribution experiment

| Planted fault | Metric that moved | Attributed? |
| --- | --- | --- |
| Chunk size 512 → 2,048 | recall 0.91 → 0.72 | Yes |
| Re-ranker disabled | precision 0.62 → 0.38 | Yes |
| Prompt loses "answer only from context" | faithfulness 0.88 → 0.61 | Yes |
| Query rewriter over-expands | relevancy 0.84 → 0.59, recall flat | Yes |
| Tool returns 3-day-old cached data | **nothing moved** | **No** |

The fifth is the important row and the one your submission must contain. Every RAG metric compares
the answer to the context; none can tell you the context is *wrong*. The check we added is not a RAG
metric at all: every evidence item carries the timestamp of the data it came from, and a case fails
if the answer relies on evidence older than its staleness tolerance. Four lines, assertion tier.

With end-to-end score alone we correctly identified 1 of 5 — and that one was the prompt change,
which we guessed because a prompt change is what people guess.

### Reference numbers

| | Value |
| --- | --- |
| Right-by-luck runs (answer right, trajectory wrong) | 35 of 400 (8.8%) |

## Why this solution and not the obvious one

**Obvious:** optimize faithfulness. It rewards refusing to answer — "I cannot determine this from the
context" scores 1.0. Our refusal rate crept from 3% to 11% after a faithfulness-focused prompt
change while the eval score improved and the product got worse. Always report relevancy and refusal
rate beside it.

**Obvious:** treat precision as an objective. A re-ranker that returns the right chunk plus two
genuinely useful neighbours lowers precision and raises quality. Precision is a diagnostic.

**Obvious:** score only the final answer. 8.8% of our successes had a wrong trajectory and regressed
three times more often on the next change. A rising end-state score with a falling trajectory score
is a warning.

## The two wrong turns worth knowing about

1. **A groundedness checker that scored world knowledge as supported.** The prompt lacked "even if the claim is true in general". The metric read 0.94 and measured nothing. Test it by passing the *wrong* document as context — if the score does not collapse, the checker is broken.
2. **Reporting the mean of a bimodal distribution.** Faithfulness mean 0.88 was 71% of cases at 1.0 and 21% below 0.5. There is no case at 0.88. Plot the histogram; store per-case values.
