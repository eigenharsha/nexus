## Reference solution — `P4-W26-M2`

### The task

Build a 500-example dataset with a written rubric, dedup and split it correctly, and measure a
baseline. Deliberately: **no training.**

### The solution that works

The pipeline is Module 2 Layer 2's `dataset_build.py`. The rubric is the part people skip, so here
it is in full — this is what a usable one looks like:

```
Score each candidate 0-3 on FOUR axes. Discard anything scoring below 3 on ANY axis.

REALISM     3 = verbatim from production traffic or a real document
            2 = lightly edited from a real one
            0-1 = invented by the author

CORRECTNESS 3 = the output is exactly what we would ship, field for field
            2 = correct but formatted differently from our convention
            0-1 = any field wrong or missing

UNAMBIGUITY 3 = two independent annotators would produce identical output
            2 = they would differ only in whitespace or ordering
            0-1 = genuine judgement call

NOVELTY     3 = a document shape not yet represented in the set
            2 = a variation on an existing shape
            0-1 = near-duplicate of something already accepted
```

### Measured numbers this produces

The funnel, on the provided 1,400 candidates:

| Stage | Count | Note |
| --- | --- | --- |
| Collected | 1,400 | |
| After exact dedup | 1,318 | 82 byte-identical |
| After near-dedup at 0.95 cosine | 1,041 | 277 near-duplicates, mostly template documents |
| After rubric (all four axes = 3) | 712 | **31.6% discarded** |
| Split 500 / 100 / 112 | 712 | absent-field coverage 19.4% |

Baseline on the 112-item test set, Llama 3.2 3B Instruct, greedy: **field F1 0.61,
95% CI [0.54, 0.68]** (paired bootstrap, 10,000 resamples).

That 31.6% discard rate is the number to expect. If yours is under 10%, your rubric is not doing
any work.

### Why this solution and not the obvious one

**The obvious solution collects 500 examples and stops.** The discipline that matters is collecting
1,400 and *discarding* 700. Module 2's Layer 3 table is unambiguous: 500 curated examples scored
0.89 while 8,000 unfiltered ones scored 0.85, in a sixteenth of the training time. Curation is
where the quality is, and a rubric written before collection is what makes curation reproducible
rather than a mood.

**The obvious split is train/val.** Three splits, because validation is contaminated by your own
tuning decisions — epoch count, learning rate, rank. A number tuned against validation and reported
as if held out is optimistic by an amount you cannot estimate.

### The two wrong turns worth knowing about

**Wrong turn 1: deduplicating after splitting.** If you split first and dedup within each split, a
document and its near-duplicate can land on opposite sides of the boundary. Three epochs over 500
examples memorises hard enough that a 0.96-similar test item is not a test. Dedup across the whole
pool, *then* split.

**Wrong turn 2: no absent-field examples.** Every collected example had every field filled, because
the documents people naturally reach for are the complete ones. A dataset where the answer is always
"here it is" trains a model that always answers — which becomes Module 4's fabrication problem. We
went back and deliberately sourced 138 documents with at least one missing field to reach 19.4%
coverage.

### Grading notes

**3/3** requires the written rubric, the full funnel with counts at every stage, a discard rate over
10%, absent-field coverage over 15%, dedup performed before splitting, and a baseline with a
confidence interval. **The most common point loss** is a baseline reported as a bare number. Second:
a rubric written retrospectively to describe what was collected, which is detectable because the
discard rate is near zero. Third: training something anyway — this module's deliverable is the
dataset and the baseline, and the discipline of not training yet is part of the exercise.
