## Reference solution — `P4-W28-M2`

### The task

Produce the three-way comparison table with confidence intervals and state whether the lift is
significant.

### The solution that works

RRF is four lines. The measurement is the deliverable:

```python
def paired_bootstrap(a, b, n=10_000, seed=0):
    rng = np.random.default_rng(seed)
    a, b = np.asarray(a), np.asarray(b)
    diffs = np.empty(n)
    for i in range(n):
        idx = rng.integers(0, len(a), len(a))     # SAME resample for both systems
        diffs[i] = b[idx].mean() - a[idx].mean()
    lo, hi = np.percentile(diffs, [2.5, 97.5])
    return b.mean() - a.mean(), lo, hi
```

### Why this solution and not the obvious one

**The obvious report gives two independent confidence intervals.** Dense's is [0.81, 0.93] and
hybrid's is [0.85, 0.95] — they overlap heavily, and concluding "not significant" from that overlap
is wrong. The queries that are hard are hard for both systems, so the *paired* difference has far
lower variance. This is the single most common statistical error in RAG write-ups and it leads teams
to discard changes that are real.

**The obvious fusion is a weighted score sum.** It ties RRF at 0.79 after a week of tuning, and it
silently regresses 0.04 when the embedding model changes. RRF is the default because it has no
tunable coupling to a score distribution.

### The two wrong turns worth knowing about

**Wrong turn 1: `INNER JOIN` in the hybrid SQL.** It keeps only documents both retrievers found,
which discards exactly the identifier hits BM25 was added for. The symptom is that hybrid gives you
the dense system's identifier score. `FULL OUTER JOIN` with `COALESCE(..., 0)`.

**Wrong turn 2: no deterministic tiebreak.** RRF's score space is coarse and ties are frequent —
about 8% of adjacent pairs in a top-10 on this corpus. Without `ORDER BY rrf DESC, id`, identical
runs return different orderings, which makes the evaluation irreproducible and the answer cache
(Module 5) unsound.

### Grading notes

**3/3** requires paired bootstrap CIs, the per-segment breakdown, and an explicit statement of
significance. Credit for the retriever-correlation table (0.31 for dense-versus-BM25), which predicts
the marginal-gain curve and justifies stopping at two. **The three most common point losses:**
independent rather than paired CIs; no segment table, which hides that fusion is repairing a
catastrophic segment rather than averaging two mediocre ones; and a tuned weighted fusion presented
as better than RRF without the robustness test that shows it breaks on a model change.
