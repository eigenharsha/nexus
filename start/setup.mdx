<Note>Everything in this course runs on macOS (Apple Silicon) and Linux x86-64. Every GPU lab has
a documented CPU or free-Colab fallback. Total cloud spend across 34 weeks: under $50.</Note>

## The one-liner

```bash
git clone https://github.com/nexus-course/nexus.git
cd nexus && ./bootstrap.sh
```

## What it installs, and when you'll first need it

| Tool | Version | First used |
| --- | --- | --- |
| `gcc` / `clang`, `make`, `valgrind` | C17 | Week 1 |
| `git`, `vim`, `tmux`, `shellcheck` | latest | Week 2 |
| `uv`, Python | 3.12 | Week 3 |
| Node | 20 LTS | Week 5 |
| Docker | 24+ | Week 7 |
| PostgreSQL (via Docker) + `pgvector` | 16 | Week 7 / Week 27 |
| Wireshark | latest | Week 10 |
| PyTorch | 2.x | Week 21 |
| `kind`, `kubectl` | latest | Week 24 |
| Ollama | latest | Week 26 |

## Verify

```bash
./bootstrap.sh --check
```

Every line should be green before Week 1. If one isn't, that's the first debugging exercise of
the course — and the setup script's failure output tells you which page to read.

<Warning>
Windows users: use WSL2 with Ubuntu 22.04+. Native Windows is not supported, and several labs
(sockets, Valgrind, Kubernetes) will behave differently in ways that will cost you hours.
</Warning>
