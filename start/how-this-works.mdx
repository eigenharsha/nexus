## A week in Nexus

Each week has **five modules**. Each module is one idea, written at [three depths](/start/three-layers),
opening with a hand-drawn diagram, and ending in something you do with your hands.
Each week has **one lab with three tracks**, and one portfolio-ready artifact.

| Day | Student (12–15 h) | Working professional (5–7 h) |
| --- | --- | --- |
| Mon–Tue | Layer 1 + Layer 2 across the five modules | Layer 2 only |
| Wed–Thu | Lab `basic` → `standard` | Lab `standard` |
| Fri | Layer 3 + the stretch challenge | Layer 3 skim |
| Sat | Lab `hard`, push to GitHub | Lab `hard` (optional) |
| Sun | Assessment, flashcards, draw-from-memory | Assessment |

## The labs

<CardGroup cols={3}>
  <Card title="basic" icon="seedling">Around 60% written for you, TODOs marked, answers provided.</Card>
  <Card title="standard" icon="hammer">A spec and a test suite. You write the implementation.</Card>
  <Card title="hard" icon="mountain">A performance, scale or robustness constraint the standard solution fails.</Card>
</CardGroup>

Every lab self-grades:

```bash
cd labs/p1/week-01
make verify     # green on a correct solution, red on the starter
```

And every lab ends in a **ship it** step — committed, deployed, containerized or measured.
A lab that ends at "it printed the right answer" hasn't ended.

## What you owe each week

<Steps>
  <Step title="One lab, at your track or above">Pushed to a public repo with a README you'd link from a resume.</Step>
  <Step title="One diagram drawn from memory">Graded. It is the highest-retention exercise here.</Step>
  <Step title="One assessment">Eight concept questions, one coding challenge, three interview questions.</Step>
  <Step title="One five-minute explanation">Recorded. Explain the week's hardest idea to an imaginary beginner.</Step>
</Steps>
