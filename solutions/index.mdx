## How to use a solution properly

<Steps>
  <Step title="Have a failing attempt first">Not a blank file. An attempt that fails, and a specific question about why.</Step>
  <Step title="Read only until you're unstuck">Then close it and go back to your own code. Don't read to the end.</Step>
  <Step title="Delete and rewrite from memory">If you can't reproduce it an hour later, you read it — you didn't learn it.</Step>
  <Step title="Diff your version against ours afterwards">The differences are the actual lesson. Ours isn't automatically better.</Step>
</Steps>

## What each solution page contains

- The full worked solution with the reasoning behind each decision
- **The two wrong turns worth knowing about** — the approaches that seem right and aren't
- The measured numbers this solution produces, so you can compare yours
- Grading notes: what a 3/3 looks like on each rubric row, and the three most common ways submissions lose points

<Note>Reading a solution before struggling with the problem feels exactly like learning. It is
the single most reliable way to finish this course having learned nothing.</Note>
