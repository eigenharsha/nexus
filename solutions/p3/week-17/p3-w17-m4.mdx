## Reference solution — `P3-W17-M4`

The task: reproduce a double-descent curve and explain why the classical U-shape story is incomplete.

## The setup that works

Random ReLU features on a linear target, minimum-norm least squares. `n = 200` training points, `d = 20` input dimensions, `N` random features swept from 10 to 10,000.

```python
# numpy 2.5.2
import numpy as np
rng = np.random.default_rng(0)
n_train, n_test, d = 200, 4000, 20
Xtr = rng.normal(size=(n_train, d)); Xte = rng.normal(size=(n_test, d))
w = rng.normal(size=d) / np.sqrt(d)
ytr = Xtr @ w + rng.normal(0, 0.15, n_train)
yte = Xte @ w + rng.normal(0, 0.15, n_test)

for N in [10, 25, 50, 100, 150, 180, 195, 199, 200, 201, 205, 220, 260, 400, 800, 1600, 4000, 10000]:
    W = np.random.default_rng(N).normal(size=(d, N)) / np.sqrt(d)
    Ztr, Zte = np.maximum(Xtr @ W, 0), np.maximum(Xte @ W, 0)
    beta = np.linalg.pinv(Ztr, rcond=1e-12) @ ytr      # MINIMUM-NORM solution
    print(N, np.mean((Ztr @ beta - ytr) ** 2), np.mean((Zte @ beta - yte) ** 2),
          np.linalg.norm(beta))
```

## The three claims, with the numbers

1. **The classical U is real.** Test MSE bottoms at 0.1843 at `N = 150` and rises after.
2. **The peak is at the interpolation threshold, and it is enormous.** 17.8218 at `N = 199` — 97x the classical optimum. `||beta||` spikes to 21.37 there.
3. **Past the threshold the error descends below the classical optimum.** 0.0569 at `N = 4,000`, which is **3.2x better** than the best under-parameterized model, with twenty times more parameters than data points.

## Why it happens — the answer is in the last column

`||beta||` is the whole explanation and it is why the deliverable requires plotting it.

- **Below the threshold** there is a unique least-squares solution. As `N` approaches `n` the feature matrix `Ztr` becomes closer and closer to square and its smallest singular value approaches zero. `beta = pinv(Z) y` divides by those singular values, so the coefficients blow up. That is the spike.
- **At `N = n`** there is exactly one exact solution and no freedom at all. Whatever noise is in `ytr` must be reproduced exactly by `beta`.
- **Above the threshold** there are infinitely many interpolating solutions and `pinv` returns the one with the smallest norm. Adding features *enlarges the solution set*, so the minimum-norm member gets smaller and smoother. `||beta||` falls monotonically from 21.37 to 0.15.

The regularization is not absent past the threshold; it has moved from the objective into the **solver's implicit bias**. This is the tabular, closed-form version of why very large neural networks trained by SGD do not simply memorise.

## Killing the peak

`Ridge(alpha=1e-2)` instead of `pinv`, same sweep:

| `N` | min-norm test MSE | ridge test MSE |
| --- | --- | --- |
| 100 | 0.2446 | 0.2432 |
| 200 | 4.0576 | **0.5797** |
| 220 | 0.6048 | 0.4913 |
| 400 | 0.0952 | 0.0949 |
| 4,000 | 0.0569 | 0.0569 |

Explicit regularization flattens the peak by **7x** at the threshold and changes essentially nothing elsewhere. This is the practical takeaway and it is the one Nakkiran et al. (2021) emphasise: the instruction is not "be over-parameterized", it is **"do not sit at `N ≈ n` unregularized"**.

## Why this solution and not the obvious one

**The obvious solution sweeps `N` on a coarse log grid — 10, 100, 1000, 10000 — and sees a monotone decrease with no peak at all.** The peak occupies a narrow band around `N = n`; with `n = 200`, the values 195 and 199 carry the story and 100 and 1,000 both look fine. Any submission whose grid does not include at least three points within 5% of `n` has not reproduced double descent, it has reproduced a smooth curve.

Two more wrong turns, both measured:

1. **Solving the normal equations instead of taking the minimum-norm solution.** `np.linalg.solve(Z.T @ Z, Z.T @ y)` works fine below the threshold and is garbage above it, because `Z.T @ Z` is singular once `N > n` and the solver returns whatever the floating-point noise in the near-null directions produces:

   | `N` | normal equation | min-norm (`pinv`) |
   | --- | --- | --- |
   | 150 | 0.1843 | 0.1843 |
   | 199 | 17.82 | 17.82 |
   | 201 | **183.7** | **0.9389** |
   | 400 | **34.93** | **0.0952** |

   A submission that does this sees the error rise and stay risen, concludes the classical story is correct, and never finds the second descent. The min-norm property is not an implementation detail — it *is* the regularizer that makes over-parameterization work.

2. **Using linear random features instead of ReLU.** `Z = X @ W` with no nonlinearity looks like it increases capacity — `N` columns instead of `d` — but the column space of `X @ W` is contained in the column space of `X`, so the model class is *identical* for every `N` above `d`. Measured test MSE: `0.0256` at `N = 50`, `150`, `199`, `201`, `400` and `4,000`. Flat. No U, no peak, no second descent. (It is also lower than the best ReLU model's 0.0569, because the true target here is linear.) The nonlinearity is what makes the feature count a real capacity knob, and this is the cheapest way to convince yourself of that.

3. **Reporting only the mean over random feature draws.** The peak is high-variance across draws by construction — that is what "the smallest singular value is near zero" means. Averaging 20 seeds gives a cleaner curve, but report the spread too; a plot showing only a mean with no error band hides the most informative part.

## Grading notes

**3/3 looks like:** the grid is dense near `N = n` (at least 195, 199, 200, 201, 205); `||beta||` is plotted on the same figure; `rcond` is set explicitly with a comment saying why; the ridge overlay is included with the peak-height reduction stated as a number; and the write-up explains the mechanism through the minimum-norm solution set rather than restating "more parameters, less overfitting".

**The three most common ways submissions lose points:**

1. **A coarse grid, so no peak.** The most common outcome, and it produces a confident write-up describing something that did not happen.
2. **Not plotting `||beta||`.** Without it the explanation is a story; with it the explanation is a measurement.
3. **Concluding "so bigger models are always better".** The measured data says the opposite at `N = 199`. The correct conclusion is that the interpolation threshold is a hazard zone, and that explicit regularization removes the hazard for a cost of essentially zero.
