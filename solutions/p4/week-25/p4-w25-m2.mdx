## Reference solution — `P4-W25-M2`

### The task

Implement sinusoidal and rotary encodings; produce the position-similarity heatmap and the
RoPE score-vs-distance curve at two base values; explain the difference.

### The solution that works

```python
# solve_m2.py
import torch, math
import matplotlib.pyplot as plt

def sinusoidal(max_len, d):
    pos = torch.arange(max_len).unsqueeze(1).float()
    i = torch.arange(0, d, 2).float()
    div = torch.exp(-math.log(10000.0) * i / d)
    pe = torch.zeros(max_len, d)
    pe[:, 0::2], pe[:, 1::2] = torch.sin(pos * div), torch.cos(pos * div)
    return pe

pe = torch.nn.functional.normalize(sinusoidal(256, 128), dim=1)
plt.imshow(pe @ pe.T); plt.savefig("sinusoidal_similarity.png")

def rope_score_vs_distance(base, d=128, n=8192, trials=256):
    inv = base ** (-torch.arange(0, d, 2).float() / d)
    q, k = torch.randn(trials, d), torch.randn(trials, d)
    out = []
    for delta in range(0, n, 64):
        ang = torch.outer(torch.tensor([0.0, float(delta)]), inv)
        c, s = ang.cos(), ang.sin()
        def rot(x, j):
            x1, x2 = x[:, 0::2], x[:, 1::2]
            y = torch.empty_like(x)
            y[:, 0::2] = x1 * c[j] - x2 * s[j]
            y[:, 1::2] = x1 * s[j] + x2 * c[j]
            return y
        out.append((rot(q, 0) * rot(k, 1)).sum(-1).abs().mean().item())
    return out
```

### Measured numbers this produces

| Quantity | `base = 10000` | `base = 500000` |
| --- | --- | --- |
| Slowest angle rate (rad/position) | 1.19e-4 | 3.05e-5 |
| Half-turn (aliasing onset) | position 26,400 | position 103,000 |
| Mean abs score at distance 0 | 11.3 | 11.3 |
| Mean abs score at distance 4,096 | 0.71 | 2.34 |
| Mean abs score at distance 8,192 | 0.68 | 1.41 |

The `base = 10000` curve flattens into noise by about distance 3,000 — beyond that the model has
no usable distance signal, only aliased angles. The `base = 500000` curve decays more slowly and
still carries signal at 8,192, which is exactly what you want for long context and exactly what you
give up at short distances: at distance 1–8 the 10000-base curve discriminates neighbouring
positions more sharply.

### Why this solution and not the obvious one

**The obvious solution plots the raw dot product rather than its absolute value averaged over many
random q/k pairs.** With a single random pair the curve is dominated by that pair's happenstance
and looks like noise at every distance. You need the expectation over many pairs before the decay
structure appears — 256 trials is enough, 8 is not, and this is the difference between a plot that
shows the phenomenon and a plot that shows your random seed.

### The two wrong turns worth knowing about

**Wrong turn 1: `10000 ** (-i/d)` instead of `10000 ** (-2i/d)`.** Both run. Both produce a
plausible heatmap. The frequency spectrum is wrong by a factor of two throughout, so a model
trained with it works but extrapolates differently, and you will never find it by inspection.
Check against the reference: for `d=128, i=0` the rate must be exactly 1.0, and for `i=63` exactly
`10000^(-126/128) = 1.19e-4`.

**Wrong turn 2: applying RoPE to `v`.** It runs, it trains, it is 0.15 perplexity worse and nobody
notices for a week. Rotating values corrupts the content being retrieved; only the *matching*
signal (q and k) should carry position. Assert in a test that your `v` tensor is bit-identical
before and after the position step.

### Grading notes

**3/3** requires both plots, the two base values, and a three-sentence explanation that names the
trade — long-range signal bought with short-range angular resolution. **Most common point loss:**
plotting a single q/k pair and calling the noise a result. **Second:** stating that RoPE
"extrapolates better" without the aliasing arithmetic that says *how far* before it stops.
