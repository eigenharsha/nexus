## Reference solution — `P4-W28-M3`

### The task

Build the gain-versus-cost scatter for six query techniques and choose a production configuration.

### The solution that works

Every transform needs three things the tutorials omit, and the tests check all three:

```python
async def safe_transform(fn, q: str, deadline_ms: int = 300):
    try:
        return await asyncio.wait_for(cached(fn, q), deadline_ms / 1000), True
    except Exception:
        return q, False        # ALWAYS degrade to the original query
```

Plus `"Keep any codes, IDs or version numbers EXACTLY as written"` in every prompt, and routing the
HyDE hypothetical to the dense retriever only.

Segment effects: HyDE takes identifier queries from **0.93 to 0.66**. Multi-query takes them to 0.81
(less damage, because the original query is one of the fused lists). Step-back gains +0.03 on
conceptual and loses 0.02 on factual — the aggregate +0.005 is two effects cancelling.

Router: classification accuracy 0.88, 62% of queries routed to plain hybrid with no expansion.

Rewrite caching: 34% repeat within 24 h; mean HyDE latency 420 ms → 277 ms.

### Why this solution and not the obvious one

**The obvious configuration turns on the techniques that helped.** HyDE at +0.02 for 420 ms p50 and
690 ms p95 is a poor trade once Module 4 is on the same axes: reranking is +0.06 for 125 ms p95.
The right output of this module is often *not* to adopt anything except the router — and stating
that is a stronger result than a pipeline with five stages.

**The obvious evaluation reports p50.** Every technique here is an LLM generation, so it has
generation-shaped tail latency: HyDE's p95 is 1.6× its p50. SLOs are made of p95, and a
p50-only table makes 690 ms look like 420.

### The two wrong turns worth knowing about

**Wrong turn 1: feeding the hypothetical to BM25.** Reference-figure NDCG 0.74 — **below the 0.79
baseline**. The fabricated passage contains plausible invented terms (parameter names, section
numbers) that BM25 matches literally against whatever documents happen to contain them. Dense side
only.

**Wrong turn 2: dropping the original query from multi-query fusion.** The generated rewrites
paraphrase identifiers away; without the original as one of the fused lists, identifier recall falls
from 0.93 to 0.81. The original must always be the first list.

### Grading notes

**3/3** requires at least four techniques, paired CIs, **added p95** rather than p50, the dollar
column, and a segment breakdown showing at least one technique that hurts. Credit for a
configuration that adopts fewer techniques than were measured. **The three most common point losses:**
p50-only latency; no segment table, so the identifier collapse is invisible; and adopting a
technique whose CI includes zero because its point estimate was positive.
