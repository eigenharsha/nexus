## Reference environment

Everything runs locally on `kind` — no cloud spend at all this week except the optional Module 5
managed-Grafana step.

| Label | Environment | Class |
| --- | --- | --- |
| **`kind` cluster** | `kind` v0.23.0, node image `kindest/node:v1.30.2`, 1 control-plane + 3 workers, in local Docker on a laptop-class host | **Measured** — reconciliation timings, pod counts and rollout behaviour are reproducible on your own laptop |
| **Machine C** | AWS `c7i.xlarge` — 4 vCPU, 8 GB — source of the Week-23 single-node serving figures | **Reference figure** — modelled, not run by the authors |

See [About the numbers](/start/about-the-numbers) for what those classes mean. Cluster timings
depend on how fast your Docker host is; the *ordering* of events (probe → endpoint removal →
rollout) is the claim, not the milliseconds.

Pinned throughout: `kubectl` **1.30.2**, `kind` **0.23.0**, Kubernetes **1.30.2**,
`metrics-server` **0.7.2**, `kube-prometheus-stack` **62.3.0** (Prometheus 2.54, Grafana 11.1),
**TensorFlow Serving 2.17.0**, `k6` **0.53.0**, KEDA **2.15.1**, Docker **24.0.7**.

```bash
cat <<'EOF' | kind create cluster --name nexus --config -
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
    kubeadmConfigPatches:
      - |
        kind: InitConfiguration
        nodeRegistration:
          kubeletExtraArgs:
            node-labels: "ingress-ready=true"
    extraPortMappings:
      - {containerPort: 80,  hostPort: 8080, protocol: TCP}
      - {containerPort: 443, hostPort: 8443, protocol: TCP}
  - role: worker
  - role: worker
  - role: worker
EOF

kind load docker-image bloodcell:v3 --name nexus     # no registry needed
kubectl get nodes
```

<Warning>
**`kind load docker-image` is the single biggest quality-of-life trick this week.** It copies an
image straight into the cluster's containerd, so you never push to a registry during
development. It also means `imagePullPolicy: IfNotPresent` — with `Always` the kubelet will try
to pull from Docker Hub, fail, and you will spend twenty minutes on `ErrImagePull` for an image
that is already there.
</Warning>
