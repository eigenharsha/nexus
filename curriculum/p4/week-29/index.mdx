## Outcome

<Note>
By Sunday you will have written an agent loop by hand, measured its reliability over 30 real tasks,
built a tool surface you can defend with numbers, and exposed shell access to a model through a
sandbox you have personally tried to break.
</Note>

The through-line of the week is one piece of arithmetic. An agent succeeds only if every step
succeeds, so end-to-end reliability is per-step reliability raised to the number of steps.
**95% per step over 10 steps is 60% end to end.** Everything else in this week — tool descriptions,
memory strategy, typed outputs, validators — is a lever on either the base or the exponent.
